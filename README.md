# QA Task Tracker

A lightweight browser-based QA task tracker for:
Patrick, Jessa, Eunice, Denise, Benjamin, Armel.

## Run
Open `index.html` in Chrome/Firefox/Safari.

No server or installation is required. Data is stored in the browser using localStorage.

## Included
- Dashboard with current task per QA member
- Add/edit tasks
- Statuses: To Do, In Progress, Blocked, For Review, Done
- Project/Game and Ticket fields
- Due date and remarks
- Search and status filters
- All Tasks view
- QA Team workload view
- Responsive layout
